## 一、购买对象与价值单位

近期付费方假设：销售负责人或业务负责人；使用者：销售、技术售前及招投标人员。真实采购方有设备需求不等于供应商有购买 BizPulse 的需求。历史中标、网站访问、试用意愿与付款不能互相替代。

收费价值单位：减少人工筛选、找到此前遗漏且满足约束的需求、给销售提供能复核的行动依据。不按未经核实的线索条数收费，不承诺中标或客户回复。交付不足如实出零结果报告，不能用历史中标或重复公告补卡片。

## 三、中国市场获客假设

优先路径：创始人通过获授权的现有关系安排访谈；行业协会/展会合作；设备与技术服务商转介；可公开展示且已获许可的案例。数据/CRM 合作伙伴需核实合同与线索归属。线上投放在价值与续费成立后再测试。

禁止把公开联系方式等同于营销授权；不自动发送邮件或企业消息。公开个人信息也需审查合理使用范围、拒绝及权益影响，不能把“网上可见”当无限处理许可。依据为[全国人大常委会公报中的个人信息保护法](https://wb.flk.npc.gov.cn/flfg/PDF/f67af9f12e1b4c83a998cf5a876ce0e4.pdf)第二十七条；具体业务上线前核实适用义务。跨境数据、再分发与客户机密另行审核，不在本文件认定合法。

|渠道|首轮试验设计，均为目标|CAC 计量|停止条件|
|---|---|---|---|
|授权关系/人工邀约|10家完成有效访谈，记录邀请与拒绝|人工工时、活动和差旅÷新增实际付费企业|有访谈无付款：CAC 未形成，不能报零|

|广告|付费与续费 Gate 后才安排小预算试验|投放+素材+销售人工÷归因付费企业|两期回收不可接受则暂停，不放量|

按渠道记录相同客户去重、归因窗口及重复接触。混合 CAC 包含销售人工；有机渠道不等于免费。小样本不推算中国市场容量。

## 四、交付成本与毛利测算

月交付成本 C = 审核工时×全成本时薪 + 来源许可分摊 + 采集/存储/模型计量 + 客户服务 + 异常返工。毛利率 =（不含税实收服务收入−C）÷不含税实收服务收入。以下使用不含税收入假设，未含研发固定成本、销售成本和企业管理费用，不能称净利润。

|月方案假设|收入|人工审核假设|其他交付成本假设|C|毛利率假设|
|---|---:|---|---:|---:|---:|
|基础订阅|799|1小时×120=120|许可80+计算40+服务60=180|300|62.5%|
|人工复核订阅|2499|8小时×120=960|许可200+计算100+服务240=540|1500|40.0%|
|同方案高复杂度|2499|16小时×120=1920|540|2460|1.6%|

人工方案由8小时变为16小时，毛利接近耗尽。不能先卖廉价不限量审核再期待模型自动解决。2499元方案若目标毛利率50%，C≤1249.5元，其他成本540元不变，则审核工时≤5.91小时；达不到应调整范围、价格或停止。

14天试点假设售价2500元，能力梳理4小时+审核6小时+复盘2小时，时薪120元，许可/计算/服务360元：C=1800元，毛利28%。这属于验证预算，不应外推长期订阅盈利。

CAC 假设：20小时销售研究×120元+活动600元=3000元；若新增2家付费，则 CAC=1500元。2499元标准方案月毛利999元，简单回收期约1.50个月；若无付费分母则 UNKNOWN。基础方案 CAC 相同、月毛利499元，约3.01个月。未考虑流失、延期、坏账和资金成本，不能据此承诺回收。

有实际续费数据后按客户队列观察累计毛利及净现金回收，先不使用“月收入÷流失率”的长周期 LTV 公式。两个月续费不能证明一年留存。

## 五、续费与价格验证

续费条件假设：客户持续使用、可复核的合格机会密度足够、相比原平台减少筛选时间、有新增信息价值、集成进入日常流程且成本可控。没有需求月份提供负结果和覆盖说明；按合同约定服务，不制造商机。

访谈依次询问：正在用哪些平台；最近一次筛选过程及实际耗时；最常见误报；遗漏如何发现；什么卡片值得销售处理；是否愿意按明确范围试用14天；什么结果才值得付费；499–999与1500–3000元/月各自是否合理、谁审批。先听需求再展示价格，保留拒绝与替代方案。

|行为|可以确认|不能确认|
|---|---|---|
|口头觉得有用|原话与特定场景反馈|付款意愿、市场需求规模|
|同意试用|特定条件下试用意愿|成交、付费转化|
|真实签署合同|购买承诺与合同金额|已收款|
|到账并履约|实收与已交付服务|未来续费、客户设备中标|
|实际续费|对应期续费行为|长期留存或因果收入提升|

## 六、商业 Gate 与风险

商业 Gate 目标：10家有效访谈中至少5家有可举证的筛选痛点；至少3家授权能力资料；至少2家实际付费试点；续费只按真实到期客户报告。目标未满足时报告样本不足或假设失败，不做“已验证”宣传。

主要风险：采购密度低、客户已有平台足够好、关键附件拿不到、人工审核贵、来源许可昂贵、采购周期长、重复机会、招投标准入误判、客户机密与联系人处理、客户把匹配当中标保证。响应：缩小场景、双边证据、明确未知、有限审核工时、拒绝非法数据、合同界定服务、失败数据也保留。

本轮不开发计费、佣金、自动销售或集成，不修改数据库。下一步执行条件见 [90天验证计划](BIZPULSE_90_DAY_VALIDATION.md)。
