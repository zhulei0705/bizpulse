日期：2026-10-09。状态：待人工确认的条件计划。本轮仅交文档并停止，不发消息、不安排自动化、不创建业务实验或客户记录。

## 一、时间与不可跨越的 Gate

Day 1 是人工批准执行计划的实际日期；不预设2026-10-09就是开始。90天是观察窗口，不是自动开发承诺。T10-C1.1 P0 PASS 不等于 C1 整体验收 PASS；未找到 T10-C1.2 通过依据，T10-C2 BLOCKED。保留安全修复、NO_AUTO_APPROVAL 和汉邦历史风险隔离。

|Gate|所需真实证据|不通过时|
|---|---|---|
|G0：任务授权|人工确认计划、负责人、预算、来源与客户安排|仅保留准备材料|
|G1：技术|T10-C1.2 正式通过报告、真实业务来源质量、证据/主体/安全复验和原通道回归；测试隔离及正式数据保护|只做访谈/模板/成本研究；不启动 C2、不规模采集|
|G2：需求与授权|10家有效访谈、至少5家具体痛点、至少3家提供真实能力资料授权，均为目标|报告实际不足/拒绝，调整场景|
|G3：交付质量|20–30合法真实业务 URL 对照及双人5–10个比较复核，证据100%可回放，严重错误0，目标合格精确率≥90%|停批修复；不足不能补造|
|G4：商业|至少2家实际付费试点，完成约定交付与真实复盘；收入、成本有依据|不开发企业级/集成，保留付费未验证|
|G5：继续投资|有到期续费、持续使用、经济性达到双方确认标准；集成由付费需求和 API 授权支撑|保持人工有限服务或终止假设|

G1 的详细技术验收标准由后续独立任务确认；本计划不能充当通过凭证。G3 可以在 G1 后以受控人工流程验证产品假设，不要求先开发 C2；任何 C2 开发仍需另行人工授权。G2 客户发现可在 G1 前进行，但不能把不可信正式机会当样例。

角色为职责建议，尚未分配真实人员。产品/商务负责人记录访谈与付费，来源合规负责人审核许可，研究员准备资料，独立审核员复核，技术负责人只按获批后续任务执行。

|窗口|可验收任务|真实产物与目标|前置/停止条件|
|---|---|---|---|
|Day 1–15|人工确认定位；审核7家官网事实；准备客户访谈、授权表、护照、证明书、成本表|一个访谈名单与依据；至少5家访谈目标；竞品未知项演示问题；不预填回复|G0；访谈需用户安排/授权；不自动邀约|
|Day 16–30|完成需求发现；量化现有筛选流程；3份授权能力资料目标|累计10家访谈目标，5家痛点目标，3份授权目标；记录拒绝与资料缺口|技术未通过仍只做此类人工研究；不解封历史证据|
|Day 31–45|G1 后验证受控真实来源与双边证据；手工参数比较和关键词基线|20–30 URL 目标，5–10比较双人复核；固定候选池及 TP/FP/FN/TN；每家最多5卡|G1/G2；严重误判、证据不一致、违规访问立即停批|
|Day 46–60|通过质量后经人工正式报价与14天试点；计时与成本|至少2家真实付费目标；实际交付、原话、工时、费用与收款凭证|G3、具体服务授权和合同；不自动外发/记录结果|
|Day 61–75|履约复盘、确认重复使用；人工导出尝试进入既有 CRM|卡片接受/拒绝、旧流程对照、实际操作及集成需求；全部 UNKNOWN 公开|G4；没有付费不做集成开发；接口写入需专项授权|
|Day 76–90|到期续费观察；按质量/价值/经济性作继续、缩小或停止决策|真实队列报告；第二行业人工可行性清单；下一任务建议|G5；未到期留存标未验证，不以90天结束制造结论|

若 Gate 延迟，不压缩质量核验或跳过授权。到 Day 90 仍停在访谈阶段也如实交付 BLOCKED/假设未验证报告。未付费可以继续低成本访谈，但必须重新审批预算，不能默认无限投入。

## 三、可直接使用的访谈提纲

开场说明研究目的、记录和使用范围，确认是否允许保留原话；拒绝录音则采用获同意的文字记录。

1. 目前使用千里马、剑鱼、其他订阅、CRM 或人工渠道吗？谁使用、谁付费？不默认客户使用任何平台。
2. 最近一次实际筛选采购需求的步骤是什么？每周处理多少条、用多久、由谁核技术参数？请求具体事件，不要求披露机密。
3. 最近出现过哪些误报：主体、过期、整机/部件、参数、地区、资质、重复？能否提供允许研究的例子？
4. 怎样发现漏报？有没有独立项目清单可核对？没有则漏报率不可测。
5. 看空白证明书结构：哪些字段缺失会让您拒绝处理？能否在5分钟内判断匹配理由及下一步？
6. 是否愿意提供授权能力资料并试用14天？您需要哪些明确范围、数据处理与退出条件？
7. 什么结果值得付费：省多少时间、多少经核验的新需求、哪些销售动作？区分认可卡片与真正购买服务。
8. 499–999元/月与1500–3000元/月两个待验证假设分别对应什么价值？预算谁批准？不把回答写成真实订单。
9. 是否接受人工文件交付？若必须集成，当前哪个系统、哪几个字段、谁能授权接口？
10. 什么情况会不续费？能否在试点结束给真实原因，并确认原话可使用范围？

仅实际行为或原话可以记录为结果。留空不是失败或认可。公开联系渠道只是核实身份的入口，本任务不抓取个人联系人、不发送邀约；后续实际触达必须人工明确授权。

## 四、研究记录模板

访谈表：企业/角色、日期、授权范围、原话及记录位置、既有平台、实际筛选耗时、误报案例、缺失、试用条件、价格回应、决策人、状态 FACT/INFERENCE/UNKNOWN。不得把内部判断写作客户原话。

护照表：主体/供货角色、产品型号配置、来源/版本/引用、单位和工况、硬能力、证书有效期、地区/交期、客户排除、资料授权、更新责任人、未知。

卡片表：采用 [PRD 模板](BIZPULSE_PRODUCT_PRD_V3.md)，附技术匹配、资格、时效、风险、双边引用、建议人工动作和审核。所有占位字段保持“待填写”，不生成虚构示范公司或公告。

反馈表：原卡版本、已送达、已回应/未回应、接受/拒绝原因、实际动作、来源原话、报价、合同、到账分别记录、客户授权。只有真实动作才写 Interaction；本轮不创建。

成本表：客户/项目、研究/审核/返工/服务分钟、计量资源、来源许可分摊、真实收入、合同口径。无法归因费用保留 UNKNOWN，不隐去创始人人工。

## 五、真实对照方法

来源样本采用许可与业务类型分层：静态、必要 JS、采购公告/意向、产品技术资料；记录拒绝、失败和缺失。不用旧沙盒 URL 凑满商业样本。相同 URL 比旧/新采集路径，保存原文/最终 URL/时间/快照/许可与版本，按 G1 后授权执行。

匹配对照固定候选池、同一日期截止口径、同一供应商配置。关键词基线预先冻结规则，不能事后挑最差规则；参数流程也冻结。两名审核员尽量不见方法名称先做原文真值，分歧由第三人裁决；客户商业接受与技术真值分开。

报告每方法 TP、FP、FN、TN，精确率=TP/(TP+FP)，召回率=TP/(TP+FN)。分母0则未验证。池不完整只能称池内召回，不能称全市场漏报率。UNKNOWN 单列覆盖率与缺失，不从分母静默剔除抬高结果。

用户计时采用相近任务、交叉顺序，记录熟悉效应。实际用时、浏览器资源、人工复核和返工均计量。指标口径与目标见 [PRD](BIZPULSE_PRODUCT_PRD_V3.md)，商业成本假设见 [商业模型](BIZPULSE_BUSINESS_MODEL_V3.md)。

## 六、预算与验收报告

90天人工研究预算假设：30–45人日×1000元=30000–45000元；来源/模型/存储/访谈活动另预留5000–10000元，总35000–55000元。未含获批后工程开发，不是已发生费用；G0 需确认可接受上限。每15天查看实际工时和费用，超上限20%暂停新增承诺并人工决定调整。

最终报告必须包含实际访谈、授权、URL、比较、客户评审、付款和到期续费的数量；失败与 UNKNOWN；严重误判；技术 Gate；付费来源；费用、毛利和 CAC 口径；对每个假设给支持/不支持/未验证。不能用计划目标写实际成果。

继续目标：无严重错误，关键证据100%回放，客户确实减少筛选负担，至少2家真实付费且交付成本可控。订阅续费目标≥50%只在到期分母明确时观察，小样本不能称长期留存已验证。若客户认为已有平台足够好，或资料不足/成本不可控，则缩小或停止。

## 七、本轮结束后的三类决策

立即可验证：官网能力与演示未知项、客户访谈、授权能力模板、空白证明书易用性、人工成本和价格假设；由人工批准执行研究。

必须等技术 Gate：真实业务采集复验、生产证据/主体/生命周期链路、受控参数匹配及 T10-C2 详细设计/开发；通过不等于自动授权。

必须等真实付费后才开发：专属 CRM/协同连接、企业级权限及复杂 SaaS、计费/佣金、跨行业自动规则规模化、双侧交易网络。付费仍需具体需求与开发授权，不能仅凭一笔付款开发所有功能。

本轮完成后停止，等待人工确认，不自行进入上述任何阶段。

## 八、BIZ-V3-01 首30天修订

首批只寻求3–5家愿交流的真实 B2B 企业，不限定行业；不是数据库中随机抽取5家。Day1为人工实际启动日。前7天确认服务范围与渠道、人工核对主体和邀约；第8–14天完成3–5次15分钟访谈目标、至少2份授权能力档案目标；第15–21天在技术/证据 Gate 通过且获授权后准备最多5卡/客户的真实样例，签前解释负结果；第22–30天提出正式试点报价、观察实际付款与评审。

报价区间14–30天999–2999元，月度2000–5000元，全部未验证。首款建议14天1999元，续期参考2999元/月；不得把旧499元低价监控问卷直接作为本轮服务报价。定价与交付范围见[收费实验](BIZPULSE_PRICING_EXPERIMENT.md)。

若 T10-C1.2 未通过，第15–30天改做空白证明书易用性、非绑定价格讨论和来源可行性研究；不承诺生产商机、不调用未验收路径做客户交付、不收费于尚无法履约服务，不开启 C2。既有业务研究引用已隔离/失效则禁止作为样例；只有公开资料也不能绕过许可和准确性审阅。

到Day30按实际访谈、痛点、审核、有效/无效/已知/愿跟进、报价、付费承诺、到账、交付和获客成本分别报告。30天目标：3–5访谈、2授权档案、1明确报价、1实际付款；阶段前提不满足就报告未验证，不凑数。10访谈及2付费留作原90天扩展目标，进入后续开发标准见首批计划。
